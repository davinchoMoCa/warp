# moca/ios-shell — Terminal integrada del iPad

Shell y herramientas compiladas para iOS arm64 que corren dentro de la app, sin servidor. iOS no deja lanzar el `zsh` del sistema (`fork`/`exec` bloqueados), así que todo va embebido y nativo, sin emular Linux.
